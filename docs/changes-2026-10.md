## Включение лайков: выполнить перед публикацией

1. Открыть SQL Editor проекта Supabase.
2. Выполнить файл `supabase/migrations/20261017_hourly_likes.sql` целиком.
3. Опубликовать проект на текущем Netlify, как обычно.

Новая Netlify Function использует уже существующие `SUPABASE_URL` и `SUPABASE_SERVICE_ROLE_KEY`. Новые секреты не нужны. Миграция сохраняет счётчик и существующее публичное чтение, добавляет отдельную таблицу блокировок и закрывает старую публичную функцию `increment_likes` для записи из браузера.

Теперь один успешный лайк блокирует повтор на час. Проверка и увеличение счётчика происходят в одной транзакции Supabase, поэтому параллельные запросы не обходят ограничение. Браузер показывает оставшееся время и сам включает кнопку после истечения часа; перезагрузка не продлевает срок. При ошибке число лайков не увеличивается.

Ограничение действует на IP-адрес: сервер хранит только HMAC-хеш адреса. Люди в одной сети могут делить лимит. Смена IP позволяет получить новый лимит — без входа в аккаунт надёжно различать отдельных людей невозможно. Очистка localStorage часовой серверный лимит не снимает.

Миграция подготовлена локально. Она не применялась к удалённому Supabase, сайт не публиковался. До её применения новый endpoint вернёт ошибку, а интерфейс сохранит число лайков и предложит повторить попытку.

## Проверки

```powershell
node --test tests/backend.test.cjs
node scripts/browser-check.mjs
```

Браузерная проверка использует установленный Chrome и временный отдельный профиль. При необходимости путь задаётся через `CHROME_PATH`. База, авторизация, Turnstile и API лайков в этом прогоне подменяются локальными ответами: реальные отзывы, сообщения и счётчики не меняются. Скриншоты сохраняются в игнорируемую папку `output/review`.

SQL следует проверять в Supabase после применения: первый POST `/api/like` возвращает 200, повторный с того же IP — 429 с прежним временем разблокировки, прежний RPC `increment_likes` недоступен анонимному клиенту. Сами SQL-транзакции локальный браузерный прогон не проверяет.
